# ExoArmur Artifact Policy

## Overview

This document defines the artifact policy for ExoArmur Core, distinguishing between canonical artifacts (tracked in git) and generated artifacts (not tracked). This policy ensures repository hygiene, determinism, and reproducibility.

## Canonical Artifacts (Tracked)

Canonical artifacts are version-controlled in git and represent the source of truth for their respective domains. These artifacts must be regenerated deterministically and committed when their source contracts change.

### OpenAPI Specification
- **Location**: `artifacts/openapi_v1.json`
- **Purpose**: REST API contract definition
- **Regeneration Command**: 
  ```bash
  python -m exoarmur.main --generate-openapi > artifacts/openapi_v1.json
  ```
- **When to Regenerate**: When API models in `src/exoarmur/api_models.py` or endpoint definitions in `src/exoarmur/main.py` change
- **Verification**: Must be committed with any API contract changes

### JSON Schemas
- **Location**: `artifacts/schemas/`
- **Purpose**: JSON schema definitions for data models
- **Regeneration Command**: Schema generation is automated via contract tests
- **When to Regenerate**: When contract models in `spec/contracts/` change
- **Verification**: Schema snapshot tests must pass

### Golden Test Artifacts
- **Location**: `tests/artifacts/`
- **Purpose**: Canonical test fixtures for deterministic replay verification
- **Examples**: `demo_canonical_events.json`
- **Regeneration**: Manual regeneration only when test semantics change intentionally
- **Verification**: Golden Demo replay hash must remain stable (7eb0f264dd6d6e67925ece66ec2218ac73716ae6bc8a770ef84a8defd28bf47b)

### Contract Snapshots
- **Location**: `spec/contracts/`
- **Purpose**: Data contract definitions (V1 locked, V2 additive)
- **Regeneration**: Manual updates only for V2 contracts; V1 contracts are immutable
- **Verification**: Contract shape tests must pass

## Generated Artifacts (Not Tracked)

Generated artifacts are created at build time, test time, or runtime and should not be committed to the repository. These are excluded by `.gitignore`.

### Build Artifacts
- **Examples**: `dist/`, `build/`, `*.egg-info/`, `*.whl`
- **Excluded by**: `.gitignore`
- **Regeneration**: `pip install -e .` or `python -m build`

### Python Cache
- **Examples**: `__pycache__/`, `*.pyc`, `*.pyo`
- **Excluded by**: `.gitignore`
- **Regeneration**: Automatic on import

### Test Cache
- **Examples**: `.pytest_cache/`, `.coverage/`, `htmlcov/`
- **Excluded by**: `.gitignore`
- **Regeneration**: Automatic on test run

### Development Cache
- **Examples**: `.mypy_cache/`, `.ruff_cache/`, `.black_cache/`
- **Excluded by**: `.gitignore`
- **Regeneration**: Automatic on tool run

### Virtual Environments
- **Examples**: `.venv/`, `venv/`, `env/`
- **Excluded by**: `.gitignore`
- **Regeneration**: `python -m venv .venv`

### Runtime Artifacts
- **Examples**: `*.log`, `*.tmp`, `*.temp`, `data/`, `audit_venv/`
- **Excluded by**: `.gitignore`
- **Regeneration**: Created at runtime

### Demo Proof Bundles
- **Examples**: `examples/demo_standalone_proof_bundle.json`, `examples/model_wrapped_demo_proof_bundle.json`
- **Excluded by**: `.gitignore`
- **Regeneration**: Generated by demo scripts on demand

### Local Configuration
- **Examples**: `.env.local`, `.env.*.local`
- **Excluded by**: `.gitignore`
- **Purpose**: Local environment overrides

### Frontend Build Artifacts
- **Examples**: `node_modules/`, `.next/`, `*.tsbuildinfo`
- **Excluded by**: `.gitignore` (defensive, in case frontend work occurs in Core)
- **Regeneration**: Frontend build process

## Artifact Integrity

### Canonical Artifact Verification

Before committing changes to canonical artifacts:

1. **Regenerate Deterministically**: Use the documented regeneration command
2. **Verify Tests Pass**: Run relevant tests to ensure artifact validity
3. **Review Diff**: Ensure changes are intentional and minimal
4. **Commit Together**: Commit artifact changes with their source changes

### Golden Demo Integrity

The Golden Demo is the canonical proof of execution boundary determinism:

- **Hash**: `7eb0f264dd6d6e67925ece66ec2218ac73716ae6bc8a770ef84a8defd28bf47b`
- **Location**: `demos/canonical_truth_reconstruction_demo.py`
- **Verification**: `python demos/canonical_truth_reconstruction_demo.py`
- **Invariant**: The replay hash must remain stable across runs and environments

### Contract Immutability

V1 contracts are permanently locked:

- **Location**: `spec/contracts/models_v1.py`
- **Policy**: No changes permitted under any circumstances
- **Verification**: Constitutional invariant tests enforce this

## Artifact Lifecycle

### Adding New Canonical Artifacts

When adding a new canonical artifact:

1. Document regeneration command in this policy
2. Add to `.gitignore` negation if needed (e.g., `!artifacts/new_artifact.json`)
3. Add verification test if applicable
4. Update this document

### Moving from Generated to Canonical

When promoting a generated artifact to canonical:

1. Ensure deterministic regeneration is possible
2. Add regeneration command to this policy
3. Update `.gitignore` to track the artifact
4. Commit the artifact
5. Update this document

### Deprecating Canonical Artifacts

When deprecating a canonical artifact:

1. Mark as deprecated in this document
2. Consider moving to `docs/history/` for reference
3. Remove from tracking if no longer needed
4. Update this document

## Artifact Storage

### Directory Structure

```
artifacts/
├── openapi_v1.json          # Canonical OpenAPI spec
└── schemas/                 # Canonical JSON schemas
    ├── AuditRecordV1.json
    ├── BeliefV1.json
    └── [additional schemas]

tests/artifacts/             # Canonical test fixtures
    ├── demo_canonical_events.json
    └── [additional fixtures]

spec/contracts/              # Canonical contract definitions
    ├── models_v1.py        # Locked V1 contracts
    ├── models_v2_*.py      # V2 contracts
    └── [additional contracts]
```

### Excluded Directories

The following directories are completely excluded from tracking:

- `__pycache__/`
- `.pytest_cache/`
- `.mypy_cache/`
- `.ruff_cache/`
- `.coverage/`
- `htmlcov/`
- `dist/`
- `build/`
- `*.egg-info/`
- `.venv/`
- `venv/`
- `env/`
- `data/`
- `audit_venv/`
- `test_install_venv/`
- `snapshot_out/`

## Compliance

### Pre-Commit Checklist

Before committing:

- [ ] No generated artifacts in the diff (except intentional canonical artifact updates)
- [ ] Canonical artifacts regenerated if their source changed
- [ ] Golden Demo hash stable (if demo changed)
- [ ] Tests pass with canonical artifacts
- [ ] `.gitignore` updated if new artifact categories added

### CI Verification

CI enforces artifact policy:

- Canonical artifact changes must pass verification tests
- Generated artifacts must be excluded by `.gitignore`
- Golden Demo replay hash must be stable
- Contract immutability tests must pass
