# Private Roadmap Notice

ExoArmur-Core contains the current deterministic governance kernel and its supporting contracts, tests, demos, and validation artifacts.

Some extension points are reserved for future private modules and advanced deployment modes. Detailed roadmap materials are intentionally omitted from this repository.

Current documentation should not be interpreted as a full roadmap disclosure, public product plan, or commitment to specific future capabilities.

Future capabilities, if any, must remain additive, feature-flagged, contract-safe, and compatible with the deterministic proof/replay discipline of Core.
