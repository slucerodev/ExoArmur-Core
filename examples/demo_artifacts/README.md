# ExoArmur-Core Demo Artifacts

This directory contains demo JSON artifacts generated from real ExoArmur-Core E2E flows. These artifacts are intended for use by ExoArmur-Web-UI as local demo data.

## Purpose

These artifacts demonstrate ExoArmur-Core's governance capabilities without requiring vendor SDKs, network calls, or external dependencies. They provide realistic sample data for UI development and testing.

## Artifacts

- **manifest.json** - Lists all demo artifacts with metadata and descriptions
- **filesystem_allow_trace.json** - Trace from allowed filesystem execution showing successful file creation
- **filesystem_deny_trace.json** - Trace from denied filesystem execution showing blocked operation
- **database_allow_trace.json** - Trace from allowed database execution showing successful table creation
- **external_effect_replay_verified.json** - External effect evidence with verified replay status
- **external_effect_tamper_detected.json** - External effect evidence with tamper detection failure

## Generation

Artifacts are generated by running:

```bash
python examples/generate_demo_artifacts.py
```

The generator script:
- Uses real Core classes (ActionIntent, ProxyPipeline, ExecutorResult, ExternalEffectEvidence, etc.)
- Executes FileSystemExecutor and DatabaseExecutor through real Core paths
- Serializes stable JSON with sorted keys and indentation
- Sanitizes all local paths before writing artifacts
- Avoids nondeterministic values where possible

## Safety

These artifacts are safe public sample data:
- No vendor SDKs or network calls required
- No machine-specific absolute paths
- No secrets, API keys, or private environment details
- All paths are sanitized to use `/tmp/demo` or `/home/demo` placeholders

## Usage

These artifacts can be loaded and displayed by ExoArmur-Web-UI to demonstrate:
- Governance trace visualization
- Policy verdict flows
- External effect evidence verification
- Tamper detection mechanisms
