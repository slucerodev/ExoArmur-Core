# ExoArmur Examples

This directory contains example scripts and demo artifacts for ExoArmur Core.

## Demo Artifacts

The `demo_artifacts/` subdirectory contains safe public sample data generated from real ExoArmur-Core E2E flows. These artifacts are intended for future Web UI/demo use.

### What Are Demo Artifacts?

Demo artifacts are JSON files that represent realistic ExoArmur execution traces and external effect evidence. They are:

- **Safe public sample data** — No secrets, no machine-specific paths, no vendor SDKs required
- **Generated from real Core classes** — Uses actual FileSystemExecutor, DatabaseExecutor, and external effect evidence
- **Deterministic and reproducible** — Sanitized to avoid non-deterministic values
- **Web UI ready** — Designed for use in ExoArmur-Web-UI or other visualization tools

### Available Artifacts

- `manifest.json` — Artifact manifest with metadata
- `filesystem_allow_trace.json` — File system allow trace example
- `filesystem_deny_trace.json` — File system deny trace example
- `database_allow_trace.json` — Database allow trace example
- `external_effect_replay_verified.json` — External effect with replay verification
- `external_effect_tamper_detected.json` — External effect with tamper detection

### Generating Demo Artifacts

Demo artifacts are generated by the `generate_demo_artifacts.py` script:

```bash
python examples/generate_demo_artifacts.py
```

This script:
- Uses real ExoArmur-Core objects and executors
- Creates realistic traces and external effect evidence
- Sanitizes paths and avoids non-deterministic values
- Outputs to `examples/demo_artifacts/`

### Using Demo Artifacts

Demo artifacts can be used to:
- Test Web UI components without requiring a live ExoArmur instance
- Demonstrate ExoArmur's trace format and evidence structure
- Develop and test visualization tools
- Provide sample data for documentation and tutorials

See [demo_artifacts/README.md](demo_artifacts/README.md) for detailed information about each artifact.

## Example Scripts

### generate_demo_artifacts.py

Script to generate demo JSON artifacts from real E2E flows. This is the primary tool for creating the demo artifacts used in Web UI and documentation.
